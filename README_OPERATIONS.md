# DramaOS 运营中心

入口：`http://127.0.0.1:8000/cms/`。使用已有 Django Admin 员工账号；超级用户可操作全部功能。普通员工需要分配对应模型的查看、增加或修改权限，运营概览需要 PageView、OutboundClick、AdEvent、Publication、ContentSource、Site 的查看权限。原 `/admin/` 保留。

## 站点与内容

站点管理可登记域名、品牌、简介、邮箱及平台目录。域名不含协议/端口，使用小写；只有已登记且启用的域名才服务公开页面。localhost / 127.0.0.1 使用默认站点；生产部署按实际入口配置 `CMS_LOCAL_HOSTS`，不要把不受信任域名加入本机别名。保存域名不会创建 DNS、服务器或证书，需在反向代理中配置域名和 HTTPS。默认站点展示现有全量平台目录，其他站点选择收录平台。

平台目录是平台介绍，不是短剧内容。已有 50 个 platform 不会被伪造为 50 部短剧。站点发布管理的是实际短剧及其本站文案。全局 Drama.status 作为旧字段保留，公开发布状态以 Publication 为准；将旧 Drama 状态设置为「隐藏」会作为全局紧急下线开关。

工作流：
1. 新增短剧，填写标题、唯一英文 slug、分类、剧情资料、标签及封面。
2. 新建授权来源：精确域名、权利人、可追溯合同或授权依据、范围、有效期、许可站点。由运营人员核验并勾选已核验。许可站点留空表示操作人确认授权适用于所有关联站点，不会替代合同审查。
3. 添加推广链接，关联来源、标记官方/授权且启用。链接域名必须精确匹配来源；若官方使用不同子域，请单独维护对应来源。
4. 从短剧列表批量创建目标站点发布草稿，或逐条新建。已有站点文案不会覆盖。
5. 撰写至少 80 字符的本站原创简介，确认原创/发布许可，生成 SEO 后人工检查并发布。批量 SEO 只生成标题和摘要，不生成剧情事实、不抓取或复制第三方正文，也不能自动证明原创性或版权。
6. 每次公开访问和推广跳转都会检查来源、授权有效期、许可站点及本站发布状态。撤销核验、关闭来源、授权到期或撤回发布后不再公开。

## CSV

导入短剧支持 UTF-8 CSV，500 行 / 2 MB；表头 `title,slug,description,language,tags`。title/description 必填，中文标题需要显式填写英文 slug。以草稿导入，原创许可不自动勾选；重复 slug 拒绝导入，任意一行出错整次回滚。Excel 可另存为 UTF-8 CSV 后导入。发布记录可以导出 CSV，危险的 Excel 公式前缀会转义。

## 广告与数据

按站点配置首页/详情页广告位，可填文字、公开横幅图片、目标 URL 和投放时间。只渲染结构化广告，旧 ad_code 不自动执行；如需 AdSense，后续应单独实现供应商、站点授权及同意管理。点击通过站点校验后跳转并记录。

统计包含站点、页面路径、短剧、链接 ID、推广活动 `utm_campaign`；例如 `/go/12/?utm_campaign=newsletter`。不保存 IP、完整 User-Agent 或 Referrer 查询串。报表显示真实 PV、外链点击、服务端广告渲染和广告点击，不等同独立用户、可见曝光或收入。忽略 CMS/admin、失败请求和常见名称带 bot 的访问；这只是基础过滤，不是反作弊系统。

## 运行与验证

保持原 `.env` 和 Python 环境。数据库更新：`python manage.py migrate`。开发启动：`python manage.py runserver`。

完整隔离测试：`python manage.py test --settings=config.test_settings`；测试使用内存 SQLite，不连接业务 MySQL。上线前按实际域名配置反向代理和 HTTPS、设置强密钥及 `DJANGO_DEBUG=0`、备份并按业务量设计日志保留策略。当前实现不包含支付、视频托管、自动权利核验、域名自动部署或外部 AI 服务。
